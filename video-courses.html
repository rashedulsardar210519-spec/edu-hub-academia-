⚙️ Connection setup checklist

  1. In Google Cloud Console, create/select a project and enable Google Drive API.
  2. Create an API key and an OAuth Client ID of type Web application. Add your GitHub Pages origin, for example https://YOUR-USERNAME.github.io, to Authorized JavaScript origins.
  3. Create a folder in Google Drive for lesson videos and copy its folder ID from the folder URL.
  4. Register your existing Firebase web app and configure Firestore. Do not publish permissive Firestore rules.
  5. Fill in the configuration constants in this HTML file and commit it to your GitHub repository.

Important privacy note: This starter is a front-end template, not a secure paid-course access system yet. A GitHub Pages page cannot securely enforce payment status by itself. For paid-only video access, use Firebase Authentication + strict Firestore rules and a secure backend/token service before sharing private Drive files. Do not set videos to “Anyone with the link” if they must remain private.
